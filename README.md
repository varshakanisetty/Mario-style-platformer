# 🎮 Mario Style Platformer

A simple 2D platformer game built using HTML, CSS, and JavaScript.

## 🚀 Features
- Player movement (left, right, jump)
- Coin collection system
- Enemy interactions
- Score tracking
- Lives system

## 🕹️ Controls
- Arrow keys / WASD → Move
- Space → Jump
